# Game Party

A browser-based party game hub. React + Vite + Tailwind client and Socket.IO server.

## Structure
- `client/` — React, Vite, Tailwind CSS, Socket.IO Client
- `server/` — Node.js and Socket.IO server

## Setup
1. Run `npm install` at the root.
2. Copy `server/.env.example` to `server/.env` and `client/.env.example` to `client/.env`.
3. Run `npm run dev`.

Client: http://localhost:5173  
Server: http://localhost:3001

Game implementations will be added after choosing the games.
